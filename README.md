# Smart Class Check-in & Learning Reflection App 🚀

**Course:** 1305216 Mobile Application Development  
**Exam:** Midterm Lab Test

## 📌 Project Overview

An MVP mobile application built with Flutter to streamline classroom check-ins and enhance student reflection. The app verifies attendance through GPS and QR scanning while collecting qualitative learning data.

## 🌐 Deployment Link

**Live Demo (Firebase Hosting):** https://smart-class-mfu-6731503015.web.app

## 🛠️ Setup & Installation

### Prerequisites

- Flutter SDK (latest version)
- Firebase CLI (for deployment)

### Instructions

1. **Clone the Repo:** https://github.com/TEERAPAT-SUKKASEM/smart-class-app.git
2. **Install Dependencies:** `flutter pub get`
3. **Run App:** `flutter run` (or `flutter run -d chrome` for web)

## ⚙️ Firebase Configuration

- The project is deployed using **Firebase Hosting**.
- Public directory is set to `build/web`.
- To deploy updates: `flutter build web` followed by `firebase deploy`.
